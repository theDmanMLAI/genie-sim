# Genie Sim

`genie-sim` is a lightweight project scaffold for simulating a genie space in a test environment.

## Goals

- Provide a minimal, easy-to-run starting point
- Give Claude Code clear project guidance
- Keep the repo ready for rapid iteration as features are added

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m src.app
```

## Repository structure

- `src/` - application source code
- `CLAUDE.md` - project-specific instructions for Claude Code
- `.gitignore` - common local and tool-generated files to ignore

## Notes

This repository started empty, so the scaffold intentionally keeps things simple and extensible.
