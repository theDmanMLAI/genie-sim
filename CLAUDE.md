# Claude Code Project Instructions

This repo is a lightweight simulation project for testing ideas around a genie space.

## Project intent

- Keep the implementation simple and easy to reason about
- Favor clear, maintainable code over clever abstractions
- Add tests for any behavior that matters to the user-facing workflow

## Working conventions

- Prefer small, focused functions and modules
- Keep documentation updated when behavior or setup changes
- Use explicit names over abbreviations where possible
- Validate changes with the lightest command that checks the affected behavior

## Suggested workflow

1. Understand the requested behavior before editing code.
2. Keep changes scoped to the task.
3. Update docs or prompts when project expectations change.
4. Run relevant validation checks before finishing.

## Repository notes

- This repository began empty; treat the current structure as a starter scaffold.
- When features are added, keep the README and this file aligned with the actual project behavior.
